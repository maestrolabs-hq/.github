# Support

## Questions about using something here

Open a discussion or an issue on the repository in question. There is no
support contract and no response-time commitment -- this is a personal estate,
and saying so is more useful than an unmet promise.

## Bugs

Open an issue with what you did, what you expected, and what happened. A
failing command and its output is worth more than a description of it.

## Security

Do not open an issue. See [SECURITY.md](SECURITY.md).
